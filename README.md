# ADMAX Banking Management System — Demo

A browser-based prototype for demonstrating common banking-office workflows.

## Included
- Dashboard summary
- Demo customer records and search
- Savings and current account records
- Simulated deposits and withdrawals with balance checks
- Transaction history and CSV export
- Demo loan-request register
- Summary report and sample-data reset
- Ghana cedi (GHS) display

## Run
Open `index.html` in a modern browser, or publish the repository with GitHub Pages.

## Important safety and scope
This is a learning/demo prototype only. It does not connect to a bank, hold funds, execute real transfers, verify identities, or make real lending decisions. Data is stored in the current browser's local storage and is not a secure database. Use fictional sample records only. Do not enter real customer details, passwords, PINs, card details, or account credentials.

A production financial service requires appropriate licensing, regulated banking/payment partners, professional security engineering, independent testing, privacy controls, and legal/regulatory review.
